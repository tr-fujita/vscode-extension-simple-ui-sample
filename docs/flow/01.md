## 雛形作成

以下のコマンドを叩きます。

```sh
npx -p yo -p generator-code yo code
```

そうすると、対話式に項目が提示されます。

### 項目1: 拡張機能のタイプ
ここでは、「TypeScriptを使ったシンプルな拡張機能」を作ります。

```sh
? What type of extension do you want to create?
❯ New Extension (TypeScript)
  New Extension (JavaScript)
  New Color Theme
  New Language Support
  New Code Snippets
  New Keymap
  New Extension Pack
  New Language Pack (Localization)
  New Web Extension (TypeScript)
  New Notebook Renderer (TypeScript)
```

### 項目2: 拡張機能の名前

```sh
? What's the name of your extension? Sample Extension
```

### 項目3: 識別子
拡張機能に対して一意な識別子を付けます。
基本的に、そのままEnterして問題ありません。

```sh
? What's the identifier of your extension? (sample-extension)
```

### 項目4: 詳細情報
拡張機能の主な機能紹介など、詳細情報を書きます。

```sh
? What's the description of your extension? This is a simple sample extension.
```

### 項目5: リポジトリの初期化
既存のリポジトリを謝って初期化しないように注意してください。

```sh
? Initialize a git repository? (Y/n)
```

### 項目6: バンドラーの選択

新規開発であれば、esbuildが標準です。（Microsoft公式が推奨）

```sh
? Which bundler to use?
  unbundled
  webpack
❯ esbuild
```

### 項目7: パッケージングツールの選択

ここではpnpmを使っています。
これについては、運用方針に従ってください。

```sh
? Which package manager to use?
  npm
  yarn
❯ pnpm
```

## 2. package.jsonを書き換える

先ほどのコマンドで作られた`package.json`を見ます。

```ts
{
  ...
  "contributes": {
    "commands": [
      {
        "command": "sample-extension.helloWorld",
        "title": "Hello World"
      }
    ]
  },
  ...
}
```

commandsには、拡張機能のコマンドを設定します。
エディタからこのコマンドを実行することが出来るようになります。

`helloWorld`コマンドは最初から作られているので、これをそのまま使ってみましょう。
