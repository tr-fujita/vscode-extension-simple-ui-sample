## extension.tsの役割

まずは、`src/extension.ts`の役割を確認しましょう。

`extension.ts`というのは、`エントリポイント`です。
ここには、拡張機能が起動した際の動きと、拡張機能が終了した際の動きを書いていきます。

---

最初、`extension.ts`には2つの関数が用意されています。

- activate
- deactivate

`activate`は、実際に拡張機能で作りたい機能を書いていきます。

`deactivate`は、拡張機能の終了時に行いたい処理を書きます。


```ts
export function activate(context: vscode.ExtensionContext) {
    console.log('Congratulations, your extension "vscode-extension-simple-ui-sample" is now active!');
    
    const disposable = vscode.commands.registerCommand('vscode-extension-simple-ui-sample.helloWorld', () => {
        vscode.window.showInformationMessage('Hello World from vscode-extension-simple-ui-sample!');
    });
    
    context.subscriptions.push(disposable);
}


export function deactivate() {}
```

## 機能を付け加える

まずは、`activate`関数の中に、簡単な通知を行う処理を付け加えてみましょう。

```diff ts
export function activate(context: vscode.ExtensionContext) {
    console.log('Congratulations, your extension "vscode-extension-simple-ui-sample" is now active!');
    
    const disposable = vscode.commands.registerCommand('vscode-extension-simple-ui-sample.helloWorld', () => {
        vscode.window.showInformationMessage('Hello World from vscode-extension-simple-ui-sample!');
+       vscode.window.showInformationMessage('試しに通知を飛ばしてみます!');
    });
    
    context.subscriptions.push(disposable);
}
```

`vscode.window.showInformationMessage()`という関数を使うことで、ポップアップ通知を出します。

処理を追加したら、`F5`キーを押してデバッグしてみてください。
